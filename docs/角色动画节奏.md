# 角色动画节奏

实现版本：v0.5.0-preview.7；随应用分发的四个角色包均升级为 1.1.0。

## 网站角色

噜噜（noah）和噜妹（草莓睡衣）保留下载到的原始 WebP 图集，只调整显式帧时长和规则。没有添加源素材不存在的跳舞等动作。

| 行为 | 先前 | 当前 |
| --- | --- | --- |
| 待机眨眼循环 | 1.56 秒 | 5.4 秒，主要停留在自然姿态 |
| 挥手 | 0.72 秒 | 1.72 秒，增加起手和回到自然姿态的停顿 |
| 跳跃 | 0.75 秒 | 1.56 秒，起跳、顶点、落地分别调整 |
| 跑两步 | 0.8 秒 | 1.84 秒 |
| 摸头闭眼反应 | 0.54 秒 | 1.24 秒，闭眼停留后恢复 |

其他思考、等待和张望动作也放缓，结束后有短暂自然姿态收尾。旧预渲染角色的动作时长约增加 40%，待机周期约增加 30%。

`v0.5.0-preview.9` 新增月薪猫，保留 9 组原始动作。月薪猫包 1.1.1 将各主动动作由约 1.93–2.48 秒延长为 4.43–6.08 秒：源帧以原速度播放三轮，只在整段起手增加 120 毫秒、结尾增加 240 毫秒，再回到基础姿态停留 320 毫秒。待机循环仍为 5.4 秒。最多排队一个动作，排队有效期延长到 8 秒，冷却 1 秒；点击、长按和抚摸使用“拍一拍”素材。

月薪猫动作按用户确认的含义显示为：额、拍一拍、向右飘过、向左飘过、蛐蛐、臭、生气、无聊、意念回复。搭子互动使用相同名称，不再把源动作描述为工作、贴贴、跳跳或伸懒腰。

网站角色最多排队一个动作。正在播放或排队的按钮会高亮并暂时禁用，避免连点重复播放；其他按钮仍能选择，忙碌时会明确反馈。面板关闭后停止刷新自身状态。

## 框架与内容边界

具体动作时长、停顿、冷却和忙碌策略仍由角色包定义。框架新增可选 `maxQueuedActions` 整数（0–8，默认 8），没有恢复固定角色或动作清单。

`bundle.json` 的 `upgradeFrom` 保存已知旧包的内容摘要。升级时只更新匹配这些历史内容的已安装包；删除过的角色不会重新出现，自定义包不自动覆盖，当前角色选择保持不变。

## 发布整理

构建使用独立发布环境，并拒绝带 NumPy 的环境。发布包检查多余计算库、PDF/QML 模块、测试、缓存、日志、私钥和个人配置；组件体积与文件摘要输出到开发者审计文件。原始下载、动画预览和审计文件不放进用户 ZIP。
