# 桌面生活与互动设计

更新：2026-10-22。合并自主活动聊天与全部扩展需求，已实现于 v0.6.0-preview.2。使用与能力边界见 [桌面生活与互动](桌面生活与互动.md)。

## 体验与分工

宠物先观察附近环境，选一个可达的窗口上沿或面板边界，走过去或借助包内跳跃动画跃过去，停下来休息。用户可以随时把它抱走、让它在这里待着，或拿出小球一起玩。到下班前十分钟和下班时，角色播放自己包里的反应。

- 环境层：桌面可用区域、可见窗口外框；可选读取前台应用提供的 UI Automation 控件类型和几何边界。不读取控件文字，不截图。识别超时由独立进程隔离，退回窗口外框。
- 行为层：自主活动间隔、探索目的地、短期访问记忆、观察/移动/休息阶段、玩球轮次与日程事件。隐藏、全屏、打开面板及手动操作优先。
- 表现层：角色包提供观察、左右移动、跳跃、休息、碰球和下班反应。动作名称保持自由；没有所需素材的包不获得相应能力。

## 本次交付范围

1. 保留现有可调随机间隔及原地、附近、自由活动范围，增加主动探索和自然行为链。
2. 探索仅在当前屏幕内选择足够宽、足够高且未被遮挡的落脚点。跳跃距离和高度受包声明与系统上限约束，行进时重新校验目标；窗口消失后恢复到可用落脚点。
3. 可选识别稳定的工具栏、面板、文档区域上沿。仅使用应用暴露的几何结构；自绘网页卡片不保证可识别。切换窗口、滚动或超时使旧结果过期。
4. 小球在当前位置附近的水平活动范围内滚动、减速和碰边反弹。角色追球并播放包声明的碰球反应；每轮最多二十秒、三次碰球，拖动松手开始新一轮。窗口边界变化、操作宠物或打开面板会收起小球。
5. 日程事件复用阈值跨越记录：下班前十分钟与到点触发，不在启动时补播、不因时钟回拨重复播放。隐藏、全屏或用户操作时跳过；支持独立开关和手动彩排。
6. 初始包通过内容摘要升级，保留自定义包、已删除角色、当前选择与个人配置。形成 Windows 可运行打包产物。

## 能力与素材

- `schedule.events/v1`：`schedule.soon`、`schedule.offwork`，按既有规则选择包内动作。
- `desktop.toys/v1`：`toys.ball` 声明可用状态及左右行走、碰球动作；移动需要 `desktop.motion/v1`。
- 探索能力沿用包内自主活动声明，额外声明观察、休息、跳跃与左右移动映射。系统不按角色名查找动作。

碰球和下班反应复用已有素材，不声称已补画专门踢球或收拾背包的动画。实际效果与角色素材一致。

## 验收

- 两个不同动作名称的包均能响应日程与玩具；缺失映射或错误移动方向在导入时拒绝。
- 自动探索无需先手动把宠物放到窗口上沿；观察、移动、休息连续，忙碌期间不堆积行为。
- 目标移动、关闭、被遮挡或显示器变化时不沿用失效路线；退出、换角色、隐藏后没有旧动作和辅助进程继续操作角色。
- UI 识别不能阻塞界面，不识别时仍可正常沿桌面/窗口活动。
- 时间跨点、回拨、休眠、禁用仪式及手动彩排不会重复触发自动仪式。
- 小球拖动/抛出/反弹、边界限制、手动动作打断、全屏与切换角色清理通过测试。

技术依据：[微软 TreeWalker API](https://learn.microsoft.com/en-us/dotnet/api/system.windows.automation.treewalker.getfirstchild)、[UI Automation 提供方](https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-providersoverview)。

## 补充交付

- 性格记忆：按角色保存昵称、互动次数和偏好；参与自主动作权重，可独立关闭或重置，数据仅在本机。
- 搭子礼物：角色包定义礼物动作与短时卡片，复用现有远程能力同步和接收控制。
- 专注陪伴：1–180 分钟，支持暂停、继续与结束；期间停止自主行为并暂停接收搭子互动，结束触发包内事件。
- 可视化角色制作室：基础图片、动作导入、矩形区域、触发规则、远程开放、真实运行时预览、校验导出及直接启用；保留素材来源与授权信息。
