# 下班搭子 v0.6.0-preview.2 · Windows 使用说明

1. 解压整个文件夹，双击 `OffworkPet.exe`。保留 `_internal` 文件夹，无需安装 Python。
2. 双击宠物打开设置，调整下班时间、工作日、大小、不透明度和气泡方式。右键面板下方“换角色”可导入、选择和删除角色包。
3. 单击和长按的反应由角色包定义；按住拖动移动窗口；Alt + 按住鼠标来回移动用于抚摸。右键打开常驻动作与互动面板，托盘可恢复位置、关闭鼠标穿透或退出。
4. Ctrl + 滚轮调大小；Ctrl + Shift + 滚轮调不透明度。

倒计时气泡默认平时隐藏，鼠标移到宠物上或单击时显示，点击后默认停留 6 秒。需要常驻时，双击宠物，在“气泡展示方式”中选择“始终展示”。

新版右键面板提供“玩小球”“下班彩排”“去逛逛”和“专注”；角色管理可设置昵称、重置偏好和打开角色制作室。详见 [桌面生活与互动](桌面生活与互动.md)。

## 与搭子互动

联网默认关闭，只使用本地功能时无需开启联网。应用已内置搭子服务，无需用户配置网络地址。

要使用双人互动，两边右键面板下方“搭子”并开启联网，再由一方生成邀请码、另一方输入并点击“连接搭子”。

角色由双方独立选择，可以同款或使用完全不同的包。搭子面板显示对方角色支持的互动，单击宠物仍然只操作自己的宠物。可以暂停接收，也可以单方面解除连接。新版动态互动需要产品服务端升级至 v2 协议。

需要在同一台电脑使用两份独立配置时，可在命令行分别运行 `OffworkPet.exe --profile alice` 与 `OffworkPet.exe --profile bob`，测试配置与主配置隔离；两者仍使用应用内置的搭子服务。

## 设置与形象

主配置保存在 `%APPDATA%\OffworkPet`，设备凭证经过 Windows 当前用户保护。换电脑或重装后，首期需要另一方解除旧关系并重新配对。

本版两个角色是根据网上参考用 Qt 绘制的同人桌面适配，不是下载的官方原画。来源见 `docs/形象来源.md`。
