# 下班搭子 v0.3.2 · Windows 使用说明

1. 解压整个文件夹，双击 `OffworkPet.exe`。保留 `_internal` 文件夹，无需安装 Python。
2. 双击宠物打开设置，选择噜噜或噜妹，调整下班时间、工作日、大小、不透明度和气泡方式。
3. 单击摸头，按住拖动，右键打开菜单；托盘可恢复位置、关闭鼠标穿透或退出。
4. Ctrl + 滚轮调大小；Ctrl + Shift + 滚轮调不透明度。

倒计时气泡默认平时隐藏，鼠标移到宠物上或单击时显示，点击后默认停留 6 秒。需要常驻时，双击宠物，在“气泡展示方式”中选择“始终展示”。

## 与搭子互动

联网默认关闭，本包没有预设公共服务地址。只有本地功能时无需开启联网。

要使用双人互动，需要先在一台服务器部署随仓库提供的搭子服务。两边右键“搭子…”，填写相同服务地址，开启联网，再由一方生成邀请码、另一方输入。没有域名可以直接使用 `http://服务器IP:8765`，也支持 HTTPS 地址。HTTP 为明文传输，HTTPS 为加密传输。

两个形象由双方独立选择，可以同款。动作通过搭子面板发送，单击宠物仍然只摸自己的宠物。可以暂停接收，也可以单方面解除连接。

详细部署与本机测试方法见本包 `docs/联网与部署.md`。本机联调可在命令行分别运行 `OffworkPet.exe --profile alice` 与 `OffworkPet.exe --profile bob`，测试配置与主配置隔离。

## 设置与形象

主配置保存在 `%APPDATA%\OffworkPet`，设备凭证经过 Windows 当前用户保护。换电脑或重装后，首期需要另一方解除旧关系并重新配对。

本版两个角色是根据网上参考用 Qt 绘制的同人桌面适配，不是下载的官方原画。来源见 `docs/形象来源.md`。
