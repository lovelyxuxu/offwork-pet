# 角色包制作与使用

适用于 `v0.6.0-preview.2`。包含本地角色包框架与可视化角色制作室；在线工坊尚未包含。制作室及桌面生活功能见 [桌面生活与互动](桌面生活与互动.md)。

首次启动默认使用你提供链接中的“噜噜（noah）”，已有角色选择继续保留。右键面板下方“换角色”可切换角色；原项目的噜噜和噜妹仍保留。也可在旧版角色包框架中单独导入 `noah-lulu.petpack`，无需重装整个应用。

## 普通用户怎么用

1. 右键宠物，在面板下方点击“换角色”。
2. 点击“导入角色包…”，选择 `.petpack` 文件，校验通过后自动启用。
3. 在角色列表切换或删除。内置的噜噜、噜妹也是普通角色，都可删除；删光后仍能右键打开管理界面重新导入。
4. 右键面板的“我的动作”显示当前包提供的按钮，点击后面板保持打开。不同角色可以提供完全不同的动作。
5. 单击、长按、悬停、拖动的反应由包定义。普通拖动移动窗口；Alt + 按住鼠标来回移动用于抚摸，须有区域及相应规则才有反应。双击仍用于打开设置。

声音、互动开关、暂停接收、隐藏和联网由系统管理。角色包不包含服务地址，双方均使用产品内置服务。远程面板展示对方当前角色提供的互动，不要求两人使用相同角色。

## 已有素材制作成包

在项目根目录安装 `requirements.txt`。下面的 `我的角色.png` 和 `跳舞.gif` 是创作者自行准备的素材路径；工具不会自动生成图片没有的新动作。

创建最小角色源目录（也可以输入 GIF/WebP）：

```powershell
python tools/character_pack.py from-image "我的角色.png" --id creator.my-character --name "我的角色" --author "作者名" --output "work/my-character"
```

工具生成封面、标准帧、`manifest.json` 和 `behavior.json`。GIF 的画面先合成为完整帧，并保留每帧时长。静态图可以直接做成零动作的角色。

把已制作好的动作 GIF 加入角色，并同时开放菜单和远程入口：

```powershell
python tools/character_pack.py add-action "work/my-character" "跳舞.gif" --id dance --label "跳舞" --remote
```

动作画布尺寸必须与角色画布一致；工具不会自动拉伸或补画不同姿态。去掉 `--remote` 则只加入本地菜单。需要摸头区域、定时反应或不同初始状态时，按格式文档修改声明；第一版仍由创作者或 AI 协助编写这些规则。

检查、预览、导出：

```powershell
python tools/character_pack.py check "work/my-character"
python tools/character_pack.py preview "work/my-character"
python tools/character_pack.py build "work/my-character" --output "outputs/my-character.petpack"
python tools/character_pack.py check "outputs/my-character.petpack"
```

预览使用正式运行时和播放器，配置与个人角色库隔离，联网默认关闭。关闭预览可从托盘或右键菜单退出。还可用 `preview <源目录或包> --snapshot outputs/preview.png` 保存静态预览并自动退出。

更新内容后先修改 `manifest.json` 中的 `version`，再导出新包。同一标识、同一版本但内容不同的包不会静默覆盖旧包。

## 包格式和运行规则

详细结构见 [角色包格式与运行规则草案](角色包格式与运行规则草案.md)。实现支持的能力：

- PNG/WebP 静态图、序列帧和显式图集矩形；每帧 `durationMs`，可选 `drawRect`。
- 自定义初始状态、基础动画、临时动作、动作结束返回或切换状态。
- 区域点击、长按、进入/离开、拖动开始/结束、Alt 抚摸的开始/更新/结束/取消。
- 定时与无操作规则、一次或重复触发、状态条件、受限布尔/数值变量、有限随机选择。
- 可选包声明的自主活动、权重、落脚点和左右位移；系统提供随机间隔、窗口边缘及用户操作时让位。字段与使用方法见 [自主活动与窗口漫步](自主活动与窗口漫步.md)。
- 优先级、打断、忙碌策略、冷却、队列去重和过期；一个主播放通道。
- 可选动作台词和 WAV 音效；系统的声音和远程文字设置优先。
- 菜单和无参数远程入口。未知必要能力、错误引用、不完整资源与不可结束的循环动作会被拒绝。

双击保留给系统设置，不开放给角色规则；尚无逐帧区域、骨骼混合、实时 3D、饱食度系统或任意脚本插件。现有格式的九行/十一行图集可通过 `tools/import_codex_pet.py` 转为显式帧、动作和菜单；v2 图集增加 `--pointer-look` 可启用基于原始朝向的鼠标跟随。噜噜（noah）和草莓睡衣噜妹均已启用，声明与边界见 [鼠标朝向跟随](鼠标朝向跟随.md)。

当前导入上限：4096 个文件、解压后 256 MiB、单张图片按 RGBA 估算不超过 32 MiB、总帧数 8192、缩略图不超过 512×512。运行帧缓存为 48 MiB，队列最多 8 项。图像最终格式造成的少量额外开销及 Qt 的内部缓存不计入这里的帧数据预算。

作者信息、素材来源与授权保存在 `manifest.json` 的 `credits` 中。示例不代替真实素材授权。

## 开发与服务端

- 默认角色包：`offwork_pet/assets/starter-packs/`；每个随版本新增的包自动导入一次；新版只自动更新内容摘要匹配历史发行版的旧包，不恢复已删除角色，也不覆盖用户自定义包。已选角色保持不变。
- 已安装角色：`%APPDATA%/OffworkPet/characters/`；版本目录与源包隔离，索引负责启用版本。已有倒计时设置独立保存。
- 网络采用 v2 能力协议，服务端仍保留 v1 供旧客户端使用。不同协议的客户端互动会明确提示升级，不自动翻译动作。
- 数据库继续持久化设备、邀请码和配对关系，角色标识复用已有文本列；本版不新增表或要求手工入库。动态能力保存在在线会话中，重连后重新同步。
- 服务器升级时必须沿用已有 `OFFWORK_DB`，不能换空数据库。开发完成不代表已经更新线上服务；v2 客户端需要配套部署新版服务端才能使用动态联网互动。

自动检查：

```powershell
python -m unittest discover -s tests -v
python tests/integration_network.py
```

旧的 `characters.py`、`sprites.py` 仅作为初始角色素材转换参考及历史素材验证保留，产品运行时不再导入它们。重新制作初始包可运行 `python tools/make_starter_packs.py`。

网站草莓睡衣噜妹的包标识为 `codex-lumei`，可通过“换角色”选择，与旧二维噜妹分别保存。

网站咕咕嘎嘎的包标识为 `gugagaga`，作者 clzd0000，是穿企鹅服的小女孩。角色包位于 `offwork_pet/assets/starter-packs/gugagaga.petpack`；已打开的旧版可通过“换角色 → 导入角色包…”立即导入并启用。随应用分发时自动新增一次，保留当前角色选择。

咕咕嘎嘎包含源图集的待机、左右跑步、挥手、跳跃、低落、等待、思考与歪头画面，以及 16 向鼠标跟随和左右张望。单击挥手，长按头部或 Alt 抚摸复用闭眼微笑帧；支持自主漫步、窗口探索、玩小球、下班仪式、专注完成反应和搭子礼物。所有行为由角色包声明，原图集保持不变。

重新制作咕咕嘎嘎（原始下载包保存在本机 `work/gugagaga-source/`）：

```powershell
python tools/import_codex_pet.py work/gugagaga-source/original.codex-pet.zip --id gugagaga --name 咕咕嘎嘎 --author clzd0000 --source-url "https://codex-pets.net/#/pets/gugagaga" --pointer-look --autonomy --output offwork_pet/assets/starter-packs/gugagaga.petpack
python -c "import json; from pathlib import Path; from tools.add_play_features import add_features; recipes=json.loads(Path('tools/recipes/starter-play.json').read_text(encoding='utf-8')); add_features('offwork_pet/assets/starter-packs/gugagaga.petpack', recipes['gugagaga'])"
```

网站月薪猫的包标识为 `monthly-salary-cat`，作者 vjokaye，包含全部 9 组源动作和 7 个远程互动入口。包 1.1.1 按用户确认的含义显示“额、拍一拍、向右飘过、向左飘过、蛐蛐、臭、生气、无聊、意念回复”，搭子入口同步使用对应名称。每次主动动作以原速度播放三轮，持续约 4.43–6.08 秒。默认保留电脑前的基础姿态；点击、长按头部和 Alt 抚摸时使用“拍一拍”动作。旧发行版角色包会随应用升级，不改变当前选择。

月薪猫按实际画面定义动作含义，网站的 Waving/Running/Review 等通用行名不直接当成角色的行为名称。转换配置位于 `tools/recipes/monthly-salary-cat.json`，仅用于制作角色包，产品运行时不读取该配置，也没有新增角色或动作分支：

```powershell
python tools/import_codex_pet.py work/monthly-salary-cat-source/original.codex-pet.zip --id monthly-salary-cat --name 月薪猫 --author vjokaye --source-url "https://codex-pets.net/#/pets/monthly-salary-cat" --recipe tools/recipes/monthly-salary-cat.json --output offwork_pet/assets/starter-packs/monthly-salary-cat.petpack
```
