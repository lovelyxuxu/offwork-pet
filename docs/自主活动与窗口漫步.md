# 自主活动与窗口漫步

首版已实现。自主活动和移动由角色包显式声明，系统不使用固定动作名称，也不把所有菜单动作自动当作自主活动。

## 使用

- 在“设置 → 偏好设置”打开“让宠物自己活动”，设置随机活动间隔；默认 20–60 秒，支持 5–3600 秒。
- “仅原地动作”过滤所有带位移的自主动作；“当前位置附近”允许围绕当前位置左右活动，范围为左右各 120 个逻辑像素，随宠物大小缩放。
- “桌面与窗口边缘”允许沿当前屏幕的桌面底部、可见窗口顶部行走。把宠物拖到一个窗口顶部附近，即可在下一次行走时落脚；窗口上方须有足够空间容纳角色。不会自动跨屏；v0.6.0 支持声明探索能力的角色主动跃往可达窗口边缘，仍受高度与距离限制。
- 托盘菜单或动作面板的“···”提供“自主活动”开关和“在这里待着”。“在这里待着”会重新以当前位置作为活动中心。
- 原有噜噜、二维噜妹增加原地自主活动；噜噜（noah）、草莓睡衣噜妹、月薪猫支持左右移动。自定义包不声明此能力时保持原有行为。

间隔从上一段活动结束后计算。动作按包内权重随机选择，刚播放过的动作降低权重。忙碌、隐藏、全屏或暂停期间不积累自动动作；恢复后重新等待完整间隔。

点击、拖动、抚摸、悬停、菜单动作及有效的搭子互动优先。打开动作面板、角色管理、搭子设置、模态对话框或系统菜单时自主活动暂歇。全屏检测暂停的是自主活动，不改变用户的声音、联网或远程接收开关。

## 移动与窗口识别

系统读取当前屏幕上的可见顶层窗口位置，使用 DWM 可见边界，并转换为 Qt 逻辑坐标。每 0.5 秒刷新一次环境；每帧按实际经过时间更新位移，卡顿或休眠后不追赶过去的路径。混合 DPI、多屏负坐标分别处理，无法匹配显示器时退回桌面边界。

被其他窗口盖住的边缘不作为落脚点。宠物沿所在窗口移动；窗口被最小化、关闭或失去可见落脚点时，停止行走并平滑回落到下方可用边缘或桌面。接近边缘和达到单次最大移动距离时停止，不从一侧穿越到另一侧。

落脚采用包的脚底坐标，而非透明图片的外框。没有落地/跳跃素材时，回落使用角色基础表现；不生成缺失的动画。只读取几何信息，不截图、不分析文本。v0.6.0 可选识别前台应用暴露的稳定内部控件边界，默认关闭；网页卡片和自绘面板不保证可识别。完整说明见 [桌面生活与互动](桌面生活与互动.md)。

Windows 边界与缩放依据：[GetWindowRect](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getwindowrect)、[Qt High DPI](https://doc.qt.io/qt-6/highdpi.html)。

## 包声明

清单 `requires` 增加 `behavior.autonomy/v1`；包含位移动作时同时增加 `desktop.motion/v1`。旧运行时会明确拒绝不支持的必要能力。

在 `behavior.json` 中声明，动作和状态标识由作者自行定义：

```json
{
  "autonomy": {
    "states": ["company"],
    "foot": [96, 198],
    "activities": [
      {"action": "observe", "weight": 3},
      {"action": "amble", "weight": 1}
    ]
  }
}
```

- `states`：允许自主活动的包内状态，至少一个。
- `foot`：画布坐标中的脚底；省略时使用画布 `anchor`。
- `activities`：最多 32 项，每项引用一个存在且不重复的动作，`weight` 默认 1。
- 候选动作继续遵守自身的状态条件和冷却。静态角色、没有行走素材的角色均不要求提供位移。

行走动作在已有动作声明上添加：

```json
"motion": {
  "direction": -1,
  "speed": 85,
  "startMs": 100,
  "endMs": 1140
}
```

`direction` 为 -1（左）或 1（右）；`speed` 为宠物大小 100% 时的逻辑像素/秒，范围 8–240。`startMs`、`endMs` 指定位移对应的动画时间段，不能超出动作时长；收尾静止帧应放在位移时间段之外。同一次漫步最多移动 180 个逻辑像素，随角色大小缩放。

位移只应用于自主调度产生的动作；用户菜单和远程互动继续播放原有动画。鼠标朝向跟随在动作期间让位，结束后按原有规则恢复。系统暂停和拖动始终能打断自主动作。

切换角色会替换整个自主控制器；旧角色的目的地、计时器和待播动作不进入新角色。官方包升级只替换内容摘要匹配已发行包的版本，保留自定义包和已删除角色。

## 制作与检查

标准外部图集转换器可用 `--autonomy` 为源格式中已有的动作生成自主声明；`--pointer-look` 仍可独立使用：

```powershell
python tools/import_codex_pet.py work/noah-lulu-source/original.codex-pet.zip --id noah-lulu --name "噜噜（noah）" --author noah --source-url "https://codex-pets.net/#/pets/noah-lulu" --pointer-look --autonomy --output offwork_pet/assets/starter-packs/noah-lulu.petpack
```

自定义转换配方可在动作项声明 `autonomousWeight` 和可选的 `motion.direction/speed`，配合 `--autonomy` 使用；不指定权重的动作不会加入自主候选。源图集的行语义只存在于转换器，产品运行时不依赖这些行名。

检查包括随机调度、操作打断、落脚点变化、遮挡、多屏坐标、配置兼容、包声明校验和 Qt 集成：

```powershell
python -m unittest discover -s tests -p "test_autonomy*.py" -v
```

原生 Windows 联调可运行 `python tests/integration_desktop_geometry.py`，会短暂打开独立测试窗口，检查可见边界、移动及最小化后落脚点移除，结束后自动关闭。
