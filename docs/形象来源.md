# 噜噜与噜妹：参考与实现说明

检索日期：2026-10-20。

## 网上参考

- [中国玩协 IP365X：水豚噜噜](https://www.ip365x.com/ip/info/1849)。页面介绍了头顶橘子的水豚噜噜，并列出所属公司铁罐（北京）文化传媒有限公司。
- [水豚噜噜官方微博内容索引](https://www.sina.cn/media/5053429838)。用于核对角色及表情风格。
- [Petdex 社区：噜妹](https://petdex.dev/pets/lumei)。社区作者 54 F. 的同人版本，描述包含黄色圆润身体、小橘子、粉色蝴蝶结和花裙。该条目不是官方形象设定或官方授权证明。
- [Petdex 社区：噜噜](https://petdex.dev/pets/orange-hippo)。同人桌宠参考，不代表原 IP 方。

检索时能确认噜噜的 IP 简介；噜妹存在多个二创版本，未核实统一官方设定。本版采用公开参考中易辨认的橘子、蝴蝶结和花裙组合，不将二创描述标成官方设定。

## 本项目如何使用

从 `v0.4.0-preview.1` 起，噜噜使用用户提供模型经 v5 调整后的透明渲染动画，素材放在 `offwork_pet/assets/lulu3d`，渲染脚本为 `tools/render_lulu_sprites.py`。运行时播放 PNG 帧，无需加载 3D 引擎或建模工程。噜妹仍由 `offwork_pet/characters.py` 使用 Qt 绘制可缩放部件与动画。

原 3D 模型“水豚噜噜”的作者为 Spencer0131，来源为 https://sketchfab.com/3d-models/a5747f74f0034470a2029a85f6e9c11d，模型许可标记为 CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）。修改包括配色、减面、头部摆正、眼睛与浅笑、基础头部/身体动画及透明渲染；发布包的 `版本说明.txt` 保留署名、来源、许可和修改说明。模型许可不等于原角色 IP 方授权。

双方可独立选同款或不同款。两个角色支持相同动作，蝴蝶结和花裙属于噜妹本版的视觉差异，不限制使用者身份。

社区素材和原 IP 的权利不因记录参考链接而转移，本项目不声称获得官方授权。后续若取得正式素材，可以通过角色绘制接口替换，不影响联网协议与配对逻辑。
