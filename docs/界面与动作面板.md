# 界面与动作面板

实现版本：v0.5.0-preview.4。

右键宠物直接打开常驻面板，主要用于频繁操作；日程、外观、角色管理及联网配对通过面板底部进入。

- **我的动作**：从当前角色包的菜单生成按钮，点击后面板不关闭；显示播放、排队、忙碌或冷却反馈。
- **搭子互动**：从对方角色实时公布的互动清单生成按钮。对方离线或暂停时禁用；换角色或解除关系后及时刷新。
- 面板默认放在宠物下方，底部空间不足时移至侧边或上方，保持在屏幕可用区域内。拖动宠物时跟随，切换到其他窗口不会自动收起；点击右上角关闭或按 Esc 收起，隐藏宠物时一并隐藏。
- 面板下方提供换角色、搭子设置、系统设置和更多操作；更多菜单及托盘仍保留隐藏、恢复位置、鼠标穿透和退出等系统功能。
- 设置按“下班日程 / 外观气泡 / 偏好设置”分组；角色管理与搭子设置统一使用浅色卡片、紫色主按钮、圆角与清晰的辅助文字。

联网前先检查服务协议。旧版服务或被转发到普通网页时，明确提示服务需要升级并停止自动重连；暂时性的网络故障继续按间隔重试。界面不向用户显示服务器地址输入。

本次定位到产品线上服务仍为协议 1，Nginx 仅转发 `/v1/*`。恢复新版联网需保留 `/var/lib/offwork-pet/offwork.sqlite3`，升级服务代码并补充 `/v2/devices` 与 `/v2/connect` 转发；不需要新建角色表或手工录入角色数据。
