# 鼠标朝向跟随

`v0.5.0-preview.10` 实现通用 `input.pointer-look/v1` 能力，草莓睡衣噜妹角色包升级为 `1.2.0`。原始图集保持不变，使用第 10、11 行的 16 个方向；同时在动作面板增加“向右张望 / 向左张望”两个入口。其他角色需要自行声明方向素材后才能使用此能力。

跟随只在包允许的空闲状态运行，不生成动作请求或占用队列，不改变搭子能力修订号。按住鼠标、拖动、抚摸、设置窗口、关闭本地互动或隐藏时暂停；主动作和远程动作优先，结束后回正停留 350 毫秒，再恢复跟随。鼠标停住约 3 秒、靠近头部中心死区或离得过远时恢复正常待机。

用户可在“设置 → 偏好设置”中勾选或取消“空闲时看向鼠标（需角色包支持）”，保存后生效并记住选择，默认开启。关闭后仍可使用单击、抚摸和动作面板；不支持方向素材的角色包维持原有表现。松开鼠标、取消操作、隐藏或切换角色时会清除按住标记，避免一次点击后持续暂停跟随。

输入在角色画布坐标下计算，经过窗口位置、系统缩放和角色绘制变换；没有固定窗口坐标或角色名判断。20 Hz 动画循环复用鼠标位置，不新增独立高频计时器。120 毫秒的向量平滑、方向边界 5 度滞回和最少 100 毫秒的换姿态间隔减少抖动，大幅转头会经过相邻的原始姿态。原图只有离散朝向，本功能不生成中间帧或逐像素旋转头部。

## 角色包声明

在 `manifest.json.requires` 加入 `input.pointer-look/v1`，并在 `behavior.json` 声明以下对象。旧版程序会明确拒绝导入所需能力未知的新包，因此完整功能需要先更新程序。

```json
{
  "pointerLook": {
    "origin": [96, 72],
    "states": ["calm_company"],
    "directions": [
      {"angle": 0, "animation": "facing_00"},
      {"angle": 90, "animation": "facing_04"},
      {"angle": 180, "animation": "facing_08"},
      {"angle": 270, "animation": "facing_12"}
    ],
    "deadZone": 20,
    "maxDistance": 1600,
    "idleTimeoutMs": 3000,
    "smoothingMs": 120,
    "switchIntervalMs": 100,
    "hysteresisDegrees": 5,
    "resumeDelayMs": 350
  }
}
```

`origin` 是画布上的注视原点。角度按屏幕坐标：上方 0°、右侧 90°、下方 180°、左侧 270°。`directions` 可声明 1–32 个不同角度，不强制 16 个，也不要求特定动画名；示例只写四个，噜妹实际逐 22.5° 声明全部 16 个。引用的动画与状态、数值边界、有限数值和必要能力在导入时验证。所有距离均为包画布单位，不是固定屏幕像素。

## 制作与升级

标准网站 v2 图集可通过适配器 `tools/import_codex_pet.py --pointer-look` 转换，固定行的含义只存在于转换器。preview.10 为草莓睡衣噜妹启用，preview.11 同样为噜噜（noah）启用；这两个包均为 1.2.0，月薪猫和历史角色包保持原样。

`bundle.json` 记录历史官方噜噜和噜妹包的摘要，自动升级仅应用于匹配的内容；已删除角色不重装，同名自定义包不覆盖。角色选择和原有搭子关系保持不变，服务端无需更新或新增数据库记录。

验证：93 项完整测试、独立发布环境下 21 项界面测试通过；原始噜妹图集逐字节一致，其他四个角色包与 preview.9 一致。实际 Windows preview.9 → preview.10 自动替换、角色版本迁移、重新启动及个人文件保留已验证。签名更新清单与安装包已发布并核对，运行时预览位于 `outputs/lumei-follow-cursor.gif`。

preview.11 为噜噜（noah）启用相同声明，不增加运行时角色分支。17 项包测试和 5 项朝向测试通过，两个角色均覆盖全部 16 个方向及动作优先；实际 preview.10 → preview.11 自动升级验证了选中的噜噜角色迁移到 1.2.0、自动重启及设置保留。噜噜原始图集逐字节保留，其他四个角色包与 preview.10 一致。运行时预览位于 `outputs/noah-follow-cursor.gif`。
