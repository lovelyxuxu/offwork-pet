# 双人互动：运行与部署

## 1. 这版包含什么

- 两个可独立选择的角色：噜噜、噜妹，允许双方同款。
- 默认关闭联网；首次主动开启后申请匿名设备身份，凭证用 Windows 当前用户 DPAPI 保护。
- 一次性 8 位邀请、10 分钟有效、撤销、一对一绑定、单方面解除。
- 安全 WebSocket 连接、状态同步、暂停、隐藏时拒收、捏脸和轻捶、350 毫秒连点合并（最多 5 次）。
- 动作 5 秒有效、标识去重、接收确认、断线重连、离线解除待同步。
- 不做注册、聊天、离线补发、已读或互动历史。

客户端与服务端都已实现，但仓库没有内置公共在线服务。两台不同电脑使用，需要共同连接一台部署好的 HTTPS 服务；不是输入邀请码就可以绕过服务端直接连接。

## 2. 本机启动服务

在仓库根目录执行：

```powershell
python -m pip install -r server/requirements.txt
python -m server --host 127.0.0.1 --port 8765
```

默认数据库为当前目录的 `data/offwork.sqlite3`。可在启动前通过环境变量 `OFFWORK_DB` 指定持久化位置，数据库及凭证均被 Git 忽略。

健康检查：`http://127.0.0.1:8765/health`。

## 3. 一台电脑验证两个独立客户端

```powershell
python main.py --profile alice
python main.py --profile bob
```

分别在两个宠物的右键“搭子…”面板填入 `http://127.0.0.1:8765` 并开启联网。一方生成邀请，另一方输入即可配对。两个配置目录和设备身份相互隔离；不需要创建两个账号。

profile 存在 `%APPDATA%/OffworkPet/profiles/<名字>`，不应在两个测试 profile 中设置开机启动。默认启动仍使用原有主配置。

测试：双方选同款/不同款，捏脸或轻捶，暂停/恢复，隐藏/显示，关闭联网/重连，离线解除后再联网。

## 4. 两台电脑或互联网使用

服务端只运行一个进程/一个 worker，当前在线会话、动作与回执在该进程的内存中。不要直接增加多个 worker，否则不同进程之间看不到对方的连接。

建议服务监听 `127.0.0.1:8765`，前置 Caddy 等反向代理处理 HTTPS/WSS。两台电脑的客户端填写相同 HTTPS 根地址，例如 `https://pet.example.com`，不填写 `/v1` 路径。示例 Caddyfile：

```caddyfile
pet.example.com {
    reverse_proxy 127.0.0.1:8765
}
```

该域名必须指向实际部署服务的机器，证书、域名与网络条件由部署环境提供。示例不代表已购买域名、开通云服务或完成公网部署。客户端拒绝远程明文 HTTP，只允许本机回环地址用于开发测试。

服务端只保存设备验证信息、当前关系和邀请，不保存动作内容。备份数据库会影响设备与关系的恢复；不要在已有客户端配对后随意换空数据库。服务重启会丢弃未完成动作，客户端重新核对关系，不补发。

## 5. 操作与状态

- 本地单击仍然摸自己的宠物，远程动作通过“搭子…”面板发送。
- 连点同一动作会合并；客户端显示“已接收”仅表示对方程序接受，不表示本人看见。
- 接收端最多每 8 秒启动 3 组远程动画，超出暂时拒绝，防止连点长期占据宠物。
- 超时或断线可能显示“未确认送达”，不自动重发，避免同一动作重复播放。
- 暂停或隐藏会停止接收且清空待播动作；穿透只影响鼠标，不影响接收。
- 断网时对方状态可能短暂滞后，心跳有效期约 30 秒；自己失联时对方状态显示未知。
- 解除连接不需要对方批准。自己离线时先停收并保存待同步解除，重连先解除再恢复其他操作。
- 换电脑/重装会产生新身份，首期由另一方解除旧关系后重新配对。

## 6. 自动验证

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python tests/integration_network.py
```

第二条测试脚本会启动临时本机服务和两个 Qt 客户端，使用临时数据库与身份目录，验证真实 HTTP 注册、WebSocket、DPAPI、配对、动作合并、接收回执、暂停、隐藏、重连和离线解除。它会生成 `outputs/` 预览，结束时关闭测试客户端和临时服务。

## 7. 当前边界

初版服务面向小范围自托管试用；尚未做多实例、凭证迁移、公共服务运营或长期负载测试。角色为按网上参考绘制的同人适配，来源见 [形象来源](形象来源.md)。
