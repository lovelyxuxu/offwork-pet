# 桌面生活与互动

适用于 v0.6.0-preview.2。完整解压发行 ZIP，退出旧版后启动 `OffworkPet.exe`，保留 `_internal` 文件夹。个人设置与已安装角色继续使用。

## 从哪里开始

| 功能 | 入口与使用 |
| --- | --- |
| 自然探索 | 右键“去逛逛”；设置中启用自主活动、主动探索及桌面与窗口边缘范围。角色观察、移动或跳跃、落脚休息。 |
| 桌面小球 | 右键“玩小球”，点击或拖动小球后松手；右键小球收起。每轮最多 20 秒、3 次碰球。 |
| 下班仪式 | 按下班时间，在前十分钟和到点播放包内反应；“下班彩排”可手动预览，偏好设置可关闭自动仪式。 |
| 性格记忆 | 角色管理填写昵称、查看熟悉度、重置记忆；偏好设置可关闭。互动偏好影响自主动作选择。 |
| 搭子礼物 | 联网并连接搭子后，在搭子互动列表选择对方角色提供的咖啡、小花或星星，接收端播放动作与短时礼物卡片。 |
| 专注陪伴 | 右键面板下方“专注”，设置 1–180 分钟，可暂停、继续或结束；倒计时显示在气泡中。 |
| 角色制作室 | 角色管理“制作自己的角色”，或更多菜单的制作入口。 |

自动活动服从手动操作、隐藏、全屏和打开面板的状态，不积压补播。专注期间暂歇自主活动、玩球与远程接收；暂停计时仍保持专注模式，结束后恢复原来的接收设置。专注计时不跨重启保存。

## 角色支持与识别范围

噜噜（noah）、草莓睡衣噜妹和咕咕嘎嘎支持窗口跳跃探索与小球；月薪猫支持水平玩球。原有二维噜噜、噜妹支持仪式、专注结束反应和礼物。自定义角色仅获得其包明确声明的能力；按钮会随角色变化。

探索在当前屏幕选择可达落脚点，要求角色上方空间足够，路线受距离与高度限制，不会跨屏或跳向任意远处。目标移动或关闭后会重新判断支撑。动画沿用包内已有素材。

“识别窗口内部面板”默认关闭。开启后，仅尝试读取前台应用通过 Windows UI Automation 暴露的控件类型和几何边界，不读取文字、不截图。工具栏、面板等须连续两次采样稳定才能成为候选；自绘网页卡片不保证识别。独立进程超时后退回外框，关闭功能会清理进程与缓存。

性格记忆是本机昵称、互动计数与动作偏好，存放于数据目录 `companions.json`。它不上传聊天内容，也不生成新动作。小球沿当前位置附近水平范围运动；操作宠物、打开面板、隐藏或换角色会收起它。

## 制作自己的角色

1. 选择或拖入 PNG、GIF、WebP 作为基础表现，填写角色名称、标识、作者、版本、素材来源与授权。
2. 添加动作图片或 GIF，填写动作名称和台词。素材画布尺寸须一致。
3. 在预览区域拖动圈选矩形互动区域，再选择单击、长按、抚摸、下班或专注结束等触发方式；也可只从菜单触发。
4. 按需开放搭子远程触发，点击“应用设置并预览动作”。勾选“试互动”后可点击预览验证区域。
5. 导出 `.petpack` 分享，或选择“导出并使用”。导出复用正式包校验；关闭未导出的草稿时会提示保存。

可以打开已有角色包继续编辑。制作室提供基础动作与规则编辑；复杂自主探索映射仍由包作者配置 JSON。工具不会自动补画缺失动画，在线工坊尚未包含。命令行工作流见 [角色包制作与使用](角色包制作与使用.md)。

## 包作者扩展

动作名称保持由包自行定义；主程序只读取能力与引用，不按角色名称硬编码。

| 清单能力 | 行为声明 |
| --- | --- |
| `schedule.events/v1` | 规则事件 `schedule.soon`、`schedule.offwork`。 |
| `focus.events/v1` | 规则事件 `focus.finished`。 |
| `desktop.toys/v1` | `toys.ball` 的 `states`、`leftAction`、`rightAction`、`touchAction`。左右动作同时需要 `desktop.motion/v1`。 |
| `desktop.explore/v1` | `autonomy.exploration` 的观察、左右移动、跳跃、休息动作映射及距离、高度、时长。沿用自主活动与移动能力。 |
| `render.gifts/v1` | 动作的 `gift` 对象：`symbol`、`label`、`durationMs`；时长 1000–30000 毫秒。 |

探索映射字段为 `observeAction`、`leftAction`、`rightAction`、`jumpAction`、`restAction`；可选 `maxRise`、`maxDrop`、`maxDistance`、`jumpDurationMs`。相关动作须可打断、忙碌时丢弃，左右动作必须有匹配方向的移动声明。跳跃位移时长不得超过动画有效时长。

初始包配方见 `tools/recipes/starter-play.json`，校验实现见 `offwork_pet/packages.py`。包升级基于内容摘要，保留自定义角色和用户已删除的初始角色。
