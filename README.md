# 下班搭子 · Offwork Pet

待在 Windows 桌面角落的噜噜或噜妹，陪你等下班，也能与一位搭子远程互动。

`v0.4.0-preview.1`：噜噜已接入 v5 形象的透明 3D 预渲染动画，支持待机呼吸/眨眼、摸头、拖动及远程动作回应；噜妹保留二维形象。设置中可确认当前形象，窗口标题显示版本号。本版不支持自由旋转的实时 3D 视角。

## 当前功能

- 噜噜、噜妹两个可独立选择的水豚角色，支持双方同款。来源及同人适配说明见 [形象来源](docs/形象来源.md)。
- 透明悬浮窗，待机呼吸、眨眼、目光跟随、歪头挥爪；摸头有回应，拖动有反应。
- 每秒更新下班倒计时，下班后显示“已下班”，工作日午夜自动重新计时。
- 自定义每周工作日、下班时间，以及仅当天生效的临时时间。
- 奶油橘 / 薄荷绿 / 云朵蓝气泡主题，50%–200% 大小，不透明度 20%–100%。调整大小和不透明度实时预览，取消后恢复。
- 气泡支持始终展示、悬停展示、点击展示、悬停或点击展示、始终隐藏五种模式。点击展示时长可设为 2–30 秒，默认 6 秒。
- 拖动移动并记住位置，置顶、鼠标穿透、系统托盘、单实例保护。
- 提前 30 分钟、10 分钟和到点提醒；声音默认关闭。
- 可选登录 Windows 时自动启动，默认关闭。
- 配置保存到 `%APPDATA%\OffworkPet\config.json`，不上传个人设置。
- 默认关闭联网；右键“搭子…”主动开启，无需注册。包含配对服务端、一次性邀请、捏脸/轻捶、暂停、断线重连、解绑及离线解除待同步。

## 双人互动

客户端需连接同一台搭子服务，本仓库不内置公共服务地址。支持 HTTP + 服务器 IP，也支持 HTTPS。完整的服务运行、部署和联调说明见 [联网与部署](docs/联网与部署.md)。

```powershell
python -m pip install -r server/requirements.txt
python -m server --port 8765
```

再分别运行 `python main.py --profile alice` 和 `python main.py --profile bob`，在两个搭子面板中填 `http://127.0.0.1:8765` 即可本机配对验证。两台不同电脑也可直接填写相同的 `http://服务器IP:8765`，服务端需监听 `0.0.0.0` 并放行相应端口，无需域名。HTTP 不加密传输，HTTPS 可在以后配置。

## 运行

Windows 10/11，Python 3.10+。推荐创建独立环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

也可以双击 `start.bat`（需先安装依赖）。默认周一到周五 18:00 下班。

拖动宠物移动，单击摸头，双击打开设置，右键打开菜单。按住 `Ctrl` 滚动鼠标滚轮调整大小，按住 `Ctrl + Shift` 滚动调整不透明度，快捷调整会自动保存。拖动和点击分开判断，拖动不会误触摸头或点击气泡。

鼠标穿透开启后，拖动、点击和滚轮快捷操作不可用，悬停气泡仍可显示。通过系统托盘右键关闭穿透，或选择“显示宠物 / 恢复位置”。托盘双击也能打开设置。

气泡默认“悬停或点击时展示”：平时隐藏，鼠标移到宠物上或单击后显示，点击后默认停留 6 秒。可在设置中改成始终展示。悬停模式离开宠物及气泡后隐藏；始终隐藏模式中摸头动作照常回应，但不显示气泡。升级会兼容旧版气泡开关，已保存的展示方式仍可自行选择。

互动仅依据鼠标位置和操作，不读取屏幕内容或启用摄像头。

## 打包为 Windows 应用

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成 `dist\v0.4.0-preview.1-3D\OffworkPet\OffworkPet.exe` 和 `dist\OffworkPet-v0.4.0-preview.1-3D.zip`。发布包包含 `版本说明.txt` 和运行所需素材，不包含 `docs`、建模工程或个人配置。目标电脑无需安装 Python 或 Blender。升级时先退出旧宠物，再完整解压并启动新版。构建依赖和产物不提交 Git。

透明动画素材已放在 `offwork_pet/assets/lulu3d`。`tools/render_lulu_sprites.py` 是从 v5 建模工程渲染的辅助脚本，需要另外准备脚本指定的 `.blend` 和 `design.json`；建模中间文件未随仓库发布。普通运行和打包直接使用现成 PNG，无需 Blender。

## 测试

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python tests/integration_network.py
```

提醒依据运行期间跨过阈值触发，启动时不会补发已过期提醒；休眠恢复后仅提醒最近跨过的一个节点。系统时间回拨不会重复触发同一节点。临时时间也可以把非工作日设为当天工作日。

## 边界与后续

当前按本机时间计算同一天的下班时间；暂不支持跨夜班、法定节假日自动同步、轮班日历和导入宠物素材。Windows 通知是否出现受系统通知设置和勿扰模式影响。

如果改动源代码或移动应用目录，请重新开启一次“登录 Windows 时自动启动”，以更新启动路径。卸载前先关闭该选项。
